# Version 0.6.2

Mode Unifié : quand une application Windows ne s'ouvre pas, la raison
s'affiche. FreeRDP qui s'arrête dans les premières secondes (affichage
XQuartz absent sur Mac, identifiants refusés, RemoteApp non autorisé…)
laissait la page sur « … s'ouvre » sans rien à l'écran ; ses lignes d'erreur
sont maintenant montrées. Le journal complet reste dans
`<données Virtua Desktop>/Local/Logs/<VM>-unified.log`.
