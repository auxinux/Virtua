# Version 0.7.1

Virtua Desktop se pilote depuis AuxiNux OS (Applications Windows, page
« Windows 11 ») : le principe de WinBoat, avec le mode Unifié de Virtua.

- `--unified-list` : VM Windows, état, mode Unifié prêt ou non, applications
  (icônes PNG en base64) et nom du lanceur de chacune, en JSON.
- `--unified-integrate <vm> on|off` : lanceurs des applications de la VM
  dans le menu (le Shell en épingle un au menu Démarrer).
- `--quick-create-windows fr-CA|en-CA` : Virtua Desktop s'ouvre en mode local
  sur la création rapide de Windows 11, langue déjà choisie.
